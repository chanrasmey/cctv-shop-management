# Project Purpose

CCTV Shop ERP is a production-oriented Enterprise Resource Planning (ERP) system designed specifically for a single CCTV retail and installation business.

The primary objective is to provide complete operational control over purchasing, inventory, sales, returns, reporting, and company management while maintaining data integrity and long-term maintainability.

The application is designed to be reliable, simple to operate, and suitable for daily business use.

---

# Development Workflow

The project follows a milestone-based development process.

Architecture and planning are reviewed before implementation.

Each milestone must satisfy:

1. Functional testing
2. Runtime validation
3. Code review
4. Documentation update

Only after these checks are completed is the milestone considered finished.
